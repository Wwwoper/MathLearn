# 📄 ТЗ: Оптимизация MathLearn для школьников

---

## 1. Обзор проекта

**Название:** MathLearn — редизайн и расширение функциональности  
**Цель:** Переработать UI/UX образовательного сайта для изучения таблицы умножения под целевую аудиторию школьников 6–12 лет  
**Исполнитель:** ИИ-агент (код-генерация + автоматизация задач)  
**Стек:** уточнить у владельца (предположительно React / Vue + backend API)

---

## 2. Целевая аудитория

- **Пользователи:** школьники 6–12 лет
- **Вторичные пользователи:** родители (мониторинг прогресса)
- **Устройства:** смартфон (приоритет), планшет, десктоп
- **Контекст использования:** дома, в школе, кратковременные сессии 5–15 минут

---

## 3. Границы работы агента

```
✅ ДЕЛАТЬ:
- Изменять CSS/стили, компоненты UI
- Создавать новые страницы и модальные окна
- Реализовывать логику прогресса, XP, бейджей
- Добавлять анимации (CSS / Framer Motion)
- Рефакторить существующие компоненты

⚠️ СПРОСИТЬ ПЕРЕД:
- Изменением схемы базы данных
- Добавлением новых npm-зависимостей
- Изменением роутинга / архитектуры

🚫 НИКОГДА:
- Не удалять существующие данные пользователей
- Не менять логику вычисления правильных ответов
- Не коммитить секреты и ключи API
```

---

## 4. Задачи по фазам

### Фаза 1 — UI-фундамент

> Выполнять задачи последовательно, каждая — отдельный PR/коммит

**Задача 1.1 — Иерархия кнопок**
- Главная CTA-кнопка «Начать урок»: ширина 100%, высота ≥ 56px, font-size 20px, цвет `#FF5722`
- Кнопка «Выбрать режим»: outline-стиль, высота 44px, вторичный цвет
- Убрать символ `●` из текста кнопки
- **Критерий приёмки:** на главной визуально доминирует одна кнопка

**Задача 1.2 — Пустые состояния**
- Если `streak === 0` → показать текст: *«Начни серию сегодня! 🔥»* вместо «0 дней подряд»
- Если `cards_queue === 0` → скрыть блок «Карточки в очереди» полностью (display: none)
- **Критерий приёмки:** новый пользователь не видит нулевых счётчиков

**Задача 1.3 — Прогресс-бар**
- Заменить текст `mastery ≥ 2.0` на `«Выучено таблиц: X из 10»`
- Добавить сетку 10 иконок (таблицы ×1…×10), статус: серый / жёлтый / зелёный
- **Критерий приёмки:** пользователь без технических знаний понимает свой прогресс

---

### Фаза 2 — Геймификация

**Задача 2.1 — Система XP**
```
Логика начисления:
- Правильный ответ с первой попытки → +10 XP
- Правильный ответ со второй попытки → +5 XP
- Неправильный ответ → 0 XP, показать подсказку

Уровни:
- Уровень 1: 0–100 XP
- Уровень 2: 100–250 XP
- Уровень 3: 250–500 XP
- (далее +150 XP на каждый уровень)

UI: шкала XP под аватаром, анимация заполнения при начислении
```
- **Критерий приёмки:** после ответа на экране видна анимация +XP

**Задача 2.2 — Стрик-анимация**
- При переходе `streak: 0 → 1` запускать анимацию поджигания факела (Lottie или CSS)
- Добавить ряд из 7 кружков-дней, текущий день подсвечивается
- **Критерий приёмки:** анимация воспроизводится после первого завершённого урока

**Задача 2.3 — Бейджи**
```
Бейдж              | Триггер
-------------------|----------------------------------
🔥 Первый огонь   | Завершить 1 урок
⚡ Молния          | Ответить на 10 примеров без ошибок
🌟 Звезда          | Выучить первую таблицу (mastery ≥ 2)
📅 Неделя          | streak = 7
🏆 Мастер          | Выучить все 10 таблиц
```
- Показывать pop-up при получении бейджа с анимацией и звуком
- Страница `/trophies` — галерея всех бейджей (полученные цветные, заблокированные серые)
- **Критерий приёмки:** бейджи отображаются корректно, pop-up появляется один раз

---

### Фаза 3 — Онбординг

**Задача 3.1 — Онбординг-флоу для новых пользователей**
```
Шаг 1: Выбор аватара (6 вариантов, сетка 2×3)
Шаг 2: Выбор класса (2, 3, 4, 5 класс — 4 кнопки)
Шаг 3: Первый мини-урок (5 примеров на таблицу ×2)
       → по завершении: выдать бейдж «Первый огонь»
```
- Показывать только при `first_visit === true`
- Кнопка «Пропустить» доступна начиная с шага 2
- **Критерий приёмки:** повторного показа онбординга не происходит после завершения

**Задача 3.2 — Персонаж-гид**
- Добавить маскота (SVG-иллюстрация совы или ракеты) в правый нижний угол
- Маскот показывает подсказки при первом посещении каждого раздела (tooltip)
- **Критерий приёмки:** тултипы отображаются только при первом посещении раздела

---

### Фаза 4 — Доступность и полировка

**Задача 4.1 — Touch и типографика**
- Все интерактивные элементы: min-height 44px, min-width 44px
- Основной текст: font-size ≥ 16px
- Цифры в примерах: font-size ≥ 32px, font-weight bold
- **Критерий приёмки:** Lighthouse Accessibility Score ≥ 90

**Задача 4.2 — Звуковая обратная связь**
```
Событие            | Звук
-------------------|-------------------------
Правильный ответ   | позитивный короткий (< 0.5с)
Неправильный ответ | мягкий нейтральный (не пугающий)
Получение бейджа   | фанфара (1–2с)
Новый уровень XP   | восходящий тон
```
- Добавить глобальный toggle «🔇 Звук» в header
- Состояние сохранять в localStorage
- **Критерий приёмки:** звуки воспроизводятся на мобильном Safari и Chrome

**Задача 4.3 — Родительский кабинет `/parent`**
- Страница с паролем (4-значный PIN)
- Показывать: время за последние 7 дней, прогресс по таблицам, топ ошибок
- **Критерий приёмки:** данные соответствуют реальной активности пользователя
